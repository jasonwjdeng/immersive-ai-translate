The Quiet Economics of Attention

A test article for Immersive AI Translate · 6 min read

Every morning, before the coffee has finished brewing, most of us hand over a small fortune without noticing. Not money — attention. The currency is invisible, but the exchange rate is brutal, and the market never closes.

Economists have a word for goods that are consumed collectively: public goods. Attention is the opposite. It is a private good that behaves like a commons, which is why it gets over-grazed. Nobody owns the meadow, so everybody brings a cow.

Why translation matters more than you think

A language is not a lookup table. It is a compression scheme for a culture, and every sentence arrives carrying assumptions that were never written down. When you translate literally, you keep the words and lose the assumptions.

"To read in a second language is to walk the same road with different shoes on. You arrive at the same place, but you feel every stone."

This is exactly why machine translation has moved from phrase-based statistical models to large language models. The older systems optimised for lexical overlap; the newer ones optimise for intent. That shift is the difference between a dictionary and a translator.

A short technical detour

Here is a code block that should be left untouched by any sane translator:

async function translate(texts) {
  const res = await fetch(endpoint, {
    method: 'POST',
    body: JSON.stringify({ segments: texts })
  });
  return res.json();
}

Inline code like requestAnimationFrame should also survive intact, as should numbers such as 3.14159, dates like 2026-10-20, and URLs like https://example.com/docs.
